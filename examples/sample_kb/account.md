# Account Help

## Creating an account

Choose Sign Up on the home page and enter a work email address. A
verification email arrives within a few minutes. Accounts stay inactive
until the address is verified.

### Verification email did not arrive

Check the spam folder first. If it is not there, request a new verification
email from the sign-in screen. Only the most recent link works; older ones
stop working as soon as a newer one is issued.

## Resetting your password

Choose Forgot Password on the sign-in screen. A reset link is emailed to the
registered address and expires after 30 minutes. Requesting a new link
invalidates any earlier one.

### Two-factor authentication

If two-factor is enabled, a reset also requires a code from the
authenticator app. Recovery codes issued at setup can be used instead if the
device is unavailable.
